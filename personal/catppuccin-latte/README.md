# Catppuccin Latte icons

A subset of [Catppuccin Icons for Zed](https://github.com/catppuccin/zed-icons), version 1.24.0, adapted for Orca. The original icons are MIT licensed; see LICENSE.

Install with `orca plugin install /absolute/path/to/personal/catppuccin-latte`, then select Catppuccin Latte Icons in Orca's icon theme settings. This port covers common file extensions and folders, not every Zed mapping; Orca limits icon themes to 512 mappings.
